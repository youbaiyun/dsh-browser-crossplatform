dsh-browser-crossplatform

让 dsh 桌面端读取并操作浏览器标签页的开源扩展 + 桥接插件。A browser bridge for the dsh desktop app.

它是什么 · What it is

一个 MV3 扩展加一个桥接插件：页面以文本形式交给模型（带编号的可操作控件），需要看图时另走可选通道（默认关闭）。支持 Windows / macOS / Linux，扩展只与桌面端桥接通信，不访问外部服务。

安装 · Install

  • 未打包（最新 0.38.8）：下载 Release 压缩包，或按 安装指南 从源码构建。
  • Chrome Web Store：商店版 0.38.7（含本轮修复的版本正在提交）。
  • npm 桥接插件：dsh-browser-crossplatform@0.38.8（产物自包含，无需补依赖）。

支持 · Support

查阅 安装与排障指南；问题请开 GitHub Issue。排障手册会先让你核对版本（桌面端 / 扩展 / 桥接）。

隐私 · Privacy

扩展不收集、不上传任何页面数据；截图与页面文本只在本机浏览器与桌面端桥接之间流转。隐私政策。
